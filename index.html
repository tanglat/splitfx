Meet SplitFX

Welcome to SplitFX, a JavaScript Text Animation Plugin

SplitFX is a JavaScript text animation plugin that splits the text of HTML elements into individual units (characters and words) and animates them.

FAQ's

Frequently Asked Questions

Find answers to common questions, questions you may have, and helpful tips about SplitFX.

  • What is SplitFX?

    SplitFX is a JavaScript text animation plugin that splits the text of HTML elements into individual characters or words and animates them. It includes a wide range of built-in text animations and gives you control over timing, delays, staggering, easing, and other animation settings.

  • What is a JavaScript text animation plugin?

    A JavaScript text animation plugin is a tool that makes it easier to create animated text effects on websites using JavaScript. SplitFX, for example, is a JavaScript text animation plugin.

  • How to add text animations to my website?

    You can add text animations to your website using a JavaScript text animation plugin such as SplitFX. SplitFX provides an easy way to add text animations to your website.

  • What text animation effects does SplitFX support?

    SplitFX includes a wide variety of built-in text animation effects, including fade, rotate, wipe, typewriter, bounce, shake, swing, blur, and more. You can also customize supported built-in text animations or create your own. See full list of built-in text animations.

  • Can I create custom text animations with SplitFX?

    Yes.
    You can customize supported built-in text animations or create your own custom animations when the built-in effects do not meet your needs. SplitFX lets you register custom animations and use them in your configurations.

  • Does SplitFX support text animations on scroll?

    Yes.
    To animate text on scroll with SplitFX, use the animateOnScroll() method to trigger animations when an element enters or leaves the viewport.
    SplitFX uses the IntersectionObserver API and provides options such as repeat, threshold, root, and rootMargin for controlling when animations are triggered.

  • Is SplitFX beginner-friendly?

    Yes.
    You can use convenience methods that make SplitFX easier to use, or core methods when you need more control over your custom logic.

  • Do I need any dependencies?

    No.
    SplitFX is dependency-free and works with plain JavaScript.

  • Can I use SplitFX on elements that contain nested elements?

    Yes.
    SplitFX allows you to split and animate the text of HTML elements even when they contain nested elements.

  • Can I animate the text of the same HTML element more than once?

    Yes.
    You can replay animations using Core Methods or configure convenience methods depending on your use case.
