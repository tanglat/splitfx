# SplitFX

> SplitFX is a JavaScript text animation plugin that splits the text of HTML elements into individual units (characters and words) and animates them.

## Features

* Animate HTML text by characters or words.
* Trigger text animations on scroll, window load, hover, or click.
* Control animation timing, stagger, stagger direction, and easing.
* Use a variety of built-in text animations.
* Create and use custom text animations.
* Control stagger direction, including forward, backward, centerOut, and random.
* Create sequential text animations with `animateSequence()`.
* Split and animate text inside HTML elements that contain nested elements.
* Use convenience methods for common animation triggers.
* Use SplitFX without external dependencies.
